Problem:
- There is no convenient way to light up my hallway in the dark

Solution:
- Build a hallway light that turns on when motion is detected to allow safe passage when it’s dark

How?
This prototype uses a passive infrared (PIR) sensor to detect motion and a light dependent resistor (LDR) to measure the amount of light.
Upon motion detection, the Arduino is instructed to immediately turn on a set of string lights for a sufficient amount of time.
